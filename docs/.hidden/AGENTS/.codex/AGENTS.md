# Codex 全局规范入口

本文件放在 `~/.codex/AGENTS.md`，作为个人全局默认规则。它只承载跨项目、跨语言、跨技术栈长期稳定的协作规则；Java、iOS、Swift、Flutter、Dart、Web、后端、脚本等具体技术栈要求，应放到对应项目的 `AGENTS.md`、技术栈规范或项目文档中。

生成、修改、审查代码时默认同时遵循：

- [全局公共规范](AGENTS.common.md)

## 使用原则

- 全局规则只放长期稳定的个人偏好、协作方式、风险边界、质量底线和完成标准。
- 不在全局规则中写具体语言、框架、平台、目录结构、测试命令、发布流程或业务架构要求。
- 技术栈、架构、目录、测试命令、发布要求放到具体项目的 `AGENTS.md`、README、CONTRIBUTING 或对应技术栈规范里。
- 用户本轮显式要求优先于全局默认；项目内更近的 `AGENTS.md`、README、CONTRIBUTING、测试配置和 lint 配置优先于全局规则。
