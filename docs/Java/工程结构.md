# 工程结构

## hhjava 当前 Maven 工程结构

当前一次 Maven Reactor 构建包含 9 个项目，其中根 POM 聚合 5 个一级模块：

```text
hhjava（父 POM，Java 17 / Spring Boot 3.3.7）
├── hhjava-unify                         通用响应、分页模型和业务码
├── hhjava-common                        异常、OpenAPI、MyBatis-Plus 自动配置
├── hhjava-service                       业务服务父模块
│   ├── hhjava-user                      用户、认证、OAuth2/JWT，可执行服务
│   └── hhjava-backup-file               文件上传/删除，可执行服务
├── hhjava-basic                         基础能力父模块
│   └── hhjava-file-starter              MinIO 自动配置与存储实现
└── hhjava-gateway                       统一入口、路由和 JWT 验签，可执行服务
```

主要依赖方向：

```text
hhjava-common -> hhjava-unify
hhjava-service -> hhjava-common
hhjava-user -> hhjava-service
hhjava-backup-file -> hhjava-service + hhjava-file-starter + hhjava-unify
hhjava-gateway -> hhjava-unify
```

`hhjava-user`、`hhjava-backup-file` 和 `hhjava-gateway` 通过 Spring Boot Maven Plugin 生成可执行 JAR。`hhjava-common` 与 `hhjava-file-starter` 通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露自动配置；它们不是独立运行服务。

完整业务、启动依赖和代码索引见 [hhjava 项目业务与代码逻辑](./hhjava项目业务与代码逻辑.md)。

## 当前共享模型与异常边界

`hhjava-unify` 维护跨服务共享的响应和业务码模型：

- `ResponseResult<T>`：统一承载 `code`、`message` 和 `data`；
- `PageRequestDto`：分页请求参数及默认值修正；
- `PageResponseResult<T>`：在统一响应上增加当前页、每页数量和总数；
- `AppHttpCodeEnum`：集中定义通用业务状态码。

`hhjava-common` 提供异常处理、OpenAPI 和 MyBatis-Plus 等共享配置，并通过 `AutoConfiguration.imports` 暴露自动配置。当前各服务的异常响应尚未完全收敛到同一种格式，因此共享模型不能替代接口级错误契约和集成测试。
