# 软件安装

## Node.js

1. 在 [Node.js 官方下载页](https://nodejs.org/en/download)选择 24.x LTS、macOS 和与你的 Mac 匹配的架构，下载安装包并完成安装。
2. 打开终端，执行：

```bash
node --version
npm --version
```

## Python

1. 在 [Python 官方 macOS 下载页](https://www.python.org/downloads/macos/)选择稳定版本的 macOS 安装包并安装。
2. 打开终端，执行：

```bash
python3 --version
```

Python 的安装与命令路径说明见 [Python macOS 官方指南](https://docs.python.org/3/using/mac.html)。
