# Cangjie Skill：把书和课程里的方法做成技能

`$cangjie-skill` 能把别人教的方法做成一个可以反复调用的新技能。你把课程材料交给仓颉，它从中提取步骤、判断条件和适用范围。以后遇到同类任务，直接调用生成的技能即可。[项目中文说明](https://github.com/kangarooking/cangjie-skill/blob/main/README.zh-CN.md)

## 什么时候值得用仓颉

以审查 App 注册页为例，可以根据下次要做的事来选：

- **希望 AI 一直遵守一个偏好。** 例如“避免不必要的辅助标签与说明，让布局本身发挥解释作用”。把这句话写进通用工程规则就够了。
- **希望以后能查到老师讲过什么。** 把抖音课程链接交给 `$douyin-to-notes`，把设计要点和示例整理成笔记。
- **希望 AI 按老师的方法审下一张页面。** 把课程转写稿和关键画面说明交给 `$cangjie-skill`，请它生成“注册页审查”技能。从原文提取怎样识别主要按钮、哪些输入要求应提前展示，以及输错后怎样提示用户。用另一张页面截图试过并验收后，今后审页面就调用这个新技能。

例如，审查意见可以具体到一行文案：“‘立即注册’按钮下的‘点击按钮完成注册’重复了，可以删。如果表单要求密码至少 8 位，就把这个要求留在密码框旁，方便用户第一次填写时就看到。”

## 第一次怎么用

1. 在 Codex 中打开一个存放资料和产物的工作目录。准备可读的书籍 PDF、EPUB、TXT、长文章或课程转写稿。视频和播客先准备字幕或逐字稿。保留章节、页码或时间标记，方便追溯方法的出处。
2. 在 Codex **对话框**中输入下面的提示，把路径、标题、作者和日期换成实际资料。首次可以只选一份材料、一个以后会重复做的任务。[官方输入要求与流程](https://github.com/kangarooking/cangjie-skill/blob/main/SKILL.md)

    ```text
    $cangjie-skill
    请读取当前工作目录中的「资料/移动端表单设计课.md」。
    课程标题为「课程标题」，讲者为「讲者姓名」，发布日期为「实际日期」。
    我的目标是以后审查 App 注册页。请提取原文中可以用于审查的步骤和判断条件，
    标出每条方法的出处。先给我看课程大纲和拟覆盖的问题，我确认后继续。
    将成果写入当前工作目录，优先生成一个可以调用的技能。
    ```

3. 收到大纲时，核对 AI 有没有读对材料和任务。收到候选方法时，抽查一条的出处和适用条件。例如，原文仅讨论密码字段，就应把这项规则限定在密码字段。遇到材料没讲清的地方，可以让它列入待核查项。
4. 选择交付方式。选 **`single`** 会得到一个调用入口，由它根据问题选用对应的方法。只有几项方法需要在不同工作流中分别调用、单独测试时，再选 **`pack`**，保留总入口并额外提供少量独立技能。[官方交付说明](https://github.com/kangarooking/cangjie-skill/blob/main/methodology/07-stage5-deliver.md)

## 怎样验收和调用生成的技能

在工作目录的 `books/<材料标识>/` 下，`DIGEST.md` 用于阅读整理后的内容，`verified.md` 记录已验证方法及其依据，`needs-review.md` 列出证据或测试仍有缺口的条目。中途退出时，让 Codex 根据同一目录里的 `PIPELINE_STATE.md` 继续。

让 Codex 给出编译产物的实际路径，然后交给它一个**原材料以外的新例子**。例如，提供另一张注册页截图，请它指出需要调整的字段、说明触发了哪条规则，并标出出处。把结果与原文核对，特别留意它有没有把作者的建议套用到了不适合的页面。编译器会检查技能格式和文件引用，实例测试用来判断这套方法能否解决你的实际问题。

验收满意、准备跨项目复用时，再告诉 Codex：“把刚才通过验收的技能安装到我的用户技能目录，告诉我它在 `SKILL.md` 中的实际名称。” 下次在对话中输入 `$实际技能名` 并附上新的任务材料即可。要从另一本书提取方法时，再调用 `$cangjie-skill`。

## 安装与自检

本机 Codex 用户目录为 `~/.codex/skills/cangjie-skill/`，安装的是官方 **v2.5.0 通用 Skill ZIP**（2026-09-13 更新）。换电脑时，从发布页下载 `cangjie-skill-2.5.0.zip` 和同名的 `.sha256` 文件，放入同一目录。在该目录执行 `shasum -a 256 -c cangjie-skill-2.5.0.zip.sha256`，显示 `OK` 后解压，把包含 `SKILL.md`、`scripts/` 和 `methodology/` 的整个 `cangjie-skill/` 目录放进 Codex 用户技能目录。打开 Codex 新会话即可调用。[官方发布包](https://github.com/kangarooking/cangjie-skill/releases/tag/v2.5.0)

本地脚本需要 Python 3.10 或以上版本及 PyYAML。本机默认的 `python3` 是 3.9.6，可以在 macOS 终端使用已有的 Python 3.13 环境运行自检，出现 `PASS` 表示所需依赖可用。让 Codex 执行编译或验证脚本时，也可以指定这一解释器。

```bash
/opt/homebrew/opt/mkdocs-material/libexec/bin/python -B \
  "$HOME/.codex/skills/cangjie-skill/scripts/cangjie.py" doctor
```

换到另一台电脑时，将命令中的解释器路径换成那台电脑上已装好 PyYAML 的 Python 3.10+ 路径。自检中 `tiktoken` 和 `jsonschema` 属于可选依赖。
